# Rothbald 0.5.0.0

## Надійність моделей

- Усі моделі тепер відкриваються саме з перевіреної локальної ревізії, яку Rothbald завантажив на стартовому екрані.
- Після оновлення моделі пошуку застосунок сам перебудовує несумісний індекс.

## Стабільна довга робота

- Rothbald не дозволяє комп’ютеру перейти в сон під час завантаження моделей, розпізнавання або індексації.
- Якщо відео змінилося посеред розпізнавання, застарілий результат не замінить попередній текст.
- Посилено відновлення після помилок диска, резервного копіювання та повторних перевірок тривалості медіа.

## Native-застосунок

- Повторний запуск Rothbald переводить фокус на вже відкрите вікно.
- Windows-збірка тепер перевіряє та пакує справжні `ffmpeg` і `ffprobe`, а не системні ярлики Chocolatey.
- Smoke-тест готової збірки запускає вбудовані медіакомпоненти до перевірки UI.

## Пошук і безпека збірки

- Повторний пошук скасовує застаріле семантичне обчислення, а великі індекси повторно використовують обмежений кеш у пам’яті.
- Python та JavaScript залежності отримали перевірку цілісності; GitHub Actions зафіксовані за commit SHA.
- Додано CodeQL, Dependabot і перелік ліцензійних повідомлень сторонніх компонентів.
