# Rothbald 0.5.0.1

## Windows

- Виправлено запуск розпізнавання на Windows: готовий застосунок тепер містить відсутню службову Python-залежність `requests`, потрібну для `faster-whisper`.
- Smoke-перевірка готової Windows-збірки імпортує весь backend розпізнавання, тому така помилка більше не пройде в інсталятор непоміченою.

## macOS

- Повторний фоновий запуск Rothbald більше не витягує його вікно поверх поточної роботи та не забирає фокус.
