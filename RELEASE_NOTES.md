# Rothbald 0.3.0.0

## GPU-прискорення Windows

- Додано локальне розпізнавання Whisper Large V3 Turbo на AMD Radeon через Vulkan.
- NVIDIA й надалі використовує оптимізований CUDA-бекенд; сумісні Intel GPU доступні через експериментальний Vulkan-режим.
- Автоматичний вибір віддає пріоритет CUDA, потім дискретній AMD через Vulkan, а за відсутності придатної GPU переходить на CPU.

## Надійність

- Якщо Vulkan не може обробити поточну частину, Rothbald безпечно повторює її на CPU, не втрачаючи попередні checkpoints.
- Після оновлення з версії без Vulkan нова знайдена GPU повторно відкриває вибір обладнання до підготовки моделей; режим `Автоматично` переходить на найкращий backend, а явний вибір CPU зберігається до ручної зміни.
- Збірка Windows використовує зафіксовані SHA-256-verified Vulkan SDK і whisper.cpp та містить точний probe Vulkan-пристроїв.
- Додано структурний review через ast-grep і регресійні перевірки маршрутизації CUDA/Vulkan/CPU, формату сегментів і прогресу.
