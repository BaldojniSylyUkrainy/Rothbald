# Rothbald 0.2.0.0

## Автоматичні оновлення

- Rothbald автоматично перевіряє наявність нової опублікованої версії після запуску.
- У застосунку можна переглянути список змін, завантажити оновлення та відкрити перевірений DMG або Windows installer.
- Маніфест оновлення захищено Ed25519-підписом, а завантажений файл повторно перевіряється за розміром і SHA-256 перед запуском.

## Релізи

- Один `RELEASE_NOTES.md` автоматично стає текстом GitHub Release і списком змін у вікні updater.
- Release зупиняється, якщо notes порожні, не відповідають версії, надто короткі або містять тестові маркери.
- Інсталятори мають зрозумілі назви для macOS Apple Silicon і Windows x64.

## Документація

- README доповнено можливостями програми, покроковим використанням та інструкціями встановлення для обох підтримуваних платформ.
- На початку README додано помітне посилання на останню версію Rothbald.
