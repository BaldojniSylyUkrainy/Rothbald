# Rothbald 0.2.0.2

## Виправлення

- Виправлено помилку, через яку після повного завантаження Rothbald не міг перевірити локальну модель розпізнавання мовлення на macOS і Windows.

## Надійність

- Завантажені snapshots тепер перевіряються за точним commit SHA Hugging Face, а не через відсутнє локальне посилання `main`.
- Rothbald додатково перевіряє наявність усіх обов’язкових файлів моделі та повторно використовує вже завантажені ваги без зайвого скачування.
