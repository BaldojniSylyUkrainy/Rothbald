# Rothbald

**rothpithnavach baldojnyi** — локальний застосунок для розпізнавання мовлення та пошуку реплік у монтажних матеріалах.

[**⬇ Завантажити останню версію Rothbald**](https://github.com/BaldojniSylyUkrainy/Rothbald/releases/latest)

Rothbald знаходить медіа в обраній папці, перетворює мовлення на текст, будує точний і смисловий пошук та відкриває потрібну репліку на таймкоді. Відео, аудіо й транскрипти не відправляються у хмару.

## Можливості

- локальне розпізнавання українського мовлення без завантаження медіа на зовнішні сервіси;
- точний пошук слів і смисловий пошук схожих за змістом реплік;
- перехід із результату одразу до потрібного відео й таймкоду;
- рекурсивна робота з папками проєктів без копіювання вихідних файлів;
- Pause/Resume із продовженням від останньої завершеної частини;
- Locate для перенесеної або перейменованої папки без повторного розпізнавання;
- автоматична перевірка підписаних оновлень із release notes безпосередньо в застосунку.

## Встановлення

### macOS — Apple Silicon

Підтримуються Mac із M1 або новішим та macOS 14.0+.

1. Відкрий [останній GitHub Release](https://github.com/BaldojniSylyUkrainy/Rothbald/releases/latest).
2. Завантаж `Rothbald-<версія>-Mac-Apple-Silicon.dmg`.
3. Відкрий DMG і перетягни Rothbald у `Applications`.
4. Запусти Rothbald як звичайний застосунок.

Коли з’явиться оновлення, Rothbald завантажить і перевірить DMG, покаже список змін та відкриє його. Після цього перетягни нову версію в `Applications` із заміною попередньої.

### Windows x64

Підтримуються 64-бітні Windows 10 22H2 і Windows 11.

1. Відкрий [останній GitHub Release](https://github.com/BaldojniSylyUkrainy/Rothbald/releases/latest).
2. Завантаж `Rothbald-<версія>-Windows-Setup.exe`.
3. Запусти installer і пройди звичайне встановлення.
4. Відкрий Rothbald через Start Menu або ярлик на робочому столі.

Коли з’явиться оновлення, Rothbald завантажить і перевірить installer, покаже список змін та запропонує його запустити. Windows може показувати `Unknown publisher`, доки проєкт не має окремого Authenticode certificate.

Для готової збірки не потрібні Python, PowerShell, ffmpeg, термінал або браузер — усе необхідне вже входить до застосунку.

## Як користуватися

1. На першому запуску підтвердь перевірку обладнання та обери режим обчислень. На Windows можна залишити `Автоматично`, вибрати доступну NVIDIA GPU або CPU; на macOS використовується Apple GPU через MLX.
2. Дочекайся завантаження й перевірки моделей. Перший запуск потребує мережі; далі вже перевірені моделі можуть працювати офлайн.
3. Натисни `Новий проєкт` і вибери папку з монтажними матеріалами. Rothbald не копіює вихідні файли.
4. Дочекайся розпізнавання або постав чергу на паузу й продовж пізніше.
5. Введи запит і переглядай вкладки `За змістом`, `Точні` та `Усі`.
6. Натисни результат, щоб відкрити відповідний файл біля потрібного таймкоду.
7. Якщо в папці з’явилися нові файли, натисни `Оновити папку`. Якщо папку або диск перенесено, скористайся `Locate`.

Видалення проєкту прибирає лише локальний індекс і транскрипти Rothbald — вихідні медіафайли не видаляються.

## Системні вимоги

Rothbald використовує великі локальні моделі та вбудований QtWebEngine. Перед завантаженням моделей застосунок сам перевіряє комп’ютер і зупиняє налаштування на критично несумісній системі.

Мінімум:

- macOS: Apple Silicon M1 або новіший, macOS 14.0+, 8 ГБ об’єднаної пам’яті;
- Windows: Windows 10 22H2 або Windows 11, x64-процесор, 8 ГБ RAM і щонайменше 4 логічні ядра;
- обидві платформи: 6 ГБ вільного місця та екран від 960 × 640.

Рекомендовано 16 ГБ пам’яті та 8 ГБ вільного місця. На Windows сумісна NVIDIA GPU значно прискорює розпізнавання; без CUDA застосунок працює на CPU повільніше.
