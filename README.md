# Rothbald

**rothpithnavach baldojnyi** — локальний застосунок для розпізнавання мовлення та пошуку реплік у монтажних матеріалах.

Rothbald знаходить відео в обраній папці, перетворює мовлення на текст, будує точний і смисловий пошук та відкриває потрібну репліку на таймкоді. Відео й транскрипти не відправляються у хмару.

## Встановлення

### Apple Silicon

1. Завантаж `Rothbald_<версія>_aarch64.dmg` зі сторінки Releases.
2. Відкрий DMG і перетягни Rothbald у Applications.
3. Запусти Rothbald як звичайний застосунок.

### Windows x64

1. Завантаж `Rothbald_<версія>_windows-x86_64-setup.exe` зі сторінки Releases.
2. Запусти інсталятор.
3. Відкрий Rothbald через Start Menu або ярлик на робочому столі.

Для готової збірки не потрібні Python, PowerShell, ffmpeg, термінал або браузер — усе необхідне вже входить до застосунку.

## Перший запуск

Rothbald автоматично перевіряє моделі на власному стартовому екрані. Якщо модель ще не завантажена або доступна новіша ревізія, застосунок показує точний прогрес, обсяг даних і приблизний час до завершення. Після цього розпізнавання та пошук працюють локально; за відсутності мережі Rothbald використовує вже перевірені моделі.

## Можливості

- «Новий проєкт» додає папку без копіювання відео.
- «Оновити папку» знаходить нові або змінені файли.
- Pause зберігає готові частини, а Resume продовжує з останньої завершеної.
- Abort скидає незавершену чергу, не видаляючи готові транскрипти.
- Locate прив’язує перенесену або перейменовану папку без повторного розпізнавання.
- Видалення проєкту прибирає лише локальний індекс Rothbald і не чіпає вихідні медіафайли.
