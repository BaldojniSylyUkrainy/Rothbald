# Rothbald

**rothpithnavach baldojnyi** — локальний застосунок для розпізнавання мовлення та пошуку реплік у монтажних матеріалах.

Rothbald знаходить відео в обраній папці, перетворює мовлення на текст, будує точний і смисловий пошук та відкриває потрібну репліку на таймкоді. Відео й транскрипти не відправляються у хмару.

## Встановлення

### Apple Silicon

1. Завантаж `Rothbald_<версія>_aarch64.dmg` зі сторінки Releases.
2. Відкрий DMG і перетягни Rothbald у Applications.
3. Запусти Rothbald як звичайний застосунок.

### Windows x64

1. Завантаж `Rothbald_<версія>_windows-x86_64-setup.exe` зі сторінки Releases.
2. Запусти інсталятор. До копіювання файлів він перевірить мінімальну RAM, місце для моделей і базову продуктивність CPU.
3. Відкрий Rothbald через Start Menu або ярлик на робочому столі.

Для готової збірки не потрібні Python, PowerShell, ffmpeg, термінал або браузер — усе необхідне вже входить до застосунку.

## Системні вимоги

Rothbald використовує великі локальні моделі та вбудований QtWebEngine, тому перед першим завантаженням моделей сам перевіряє комп’ютер. Якщо конфігурація слабша за рекомендовану, застосунок попередить про можливе гальмування; критично несумісна система не почне завантаження моделей.

### Мінімум

- **macOS:** Apple Silicon M1 або новіший, macOS 13.5+, 8 ГБ об’єднаної пам’яті.
- **Windows:** Windows 10 22H2 або Windows 11, 64-бітний x64-процесор, 8 ГБ RAM, щонайменше 4 логічні ядра.
- **Для обох платформ:** 12 ГБ вільного місця для застосунку, моделей і робочого кешу; екран від 960 × 640.

### Рекомендовано

- 16 ГБ RAM або об’єднаної пам’яті.
- 20 ГБ вільного місця, особливо для великих відеопроєктів.
- На macOS розпізнавання автоматично використовує Apple GPU через MLX.
- На Windows сумісна NVIDIA GPU прискорює розпізнавання. Якщо CUDA недоступна, Rothbald працює на CPU, але значно повільніше.

Під час першого запуску можна вибрати **Автоматично**, конкретну доступну NVIDIA GPU або **CPU**. Вибір зберігається локально й буде запитаний повторно, якщо зміниться обладнання або доступність драйверів.

## Перший запуск

Спочатку Rothbald перевіряє архітектуру, RAM, процесор, вільне місце та доступні обчислювальні пристрої. Лише після підтвердження запускається перевірка моделей. Якщо модель ще не завантажена або доступна новіша ревізія, застосунок показує точний прогрес, обсяг даних і приблизний час до завершення. Після цього розпізнавання та пошук працюють локально; за відсутності мережі Rothbald використовує вже перевірені моделі.

## Можливості

- «Новий проєкт» додає папку без копіювання відео.
- «Оновити папку» знаходить нові або змінені файли.
- Pause зберігає готові частини, а Resume продовжує з останньої завершеної.
- Abort скидає незавершену чергу, не видаляючи готові транскрипти.
- Locate прив’язує перенесену або перейменовану папку без повторного розпізнавання.
- Видалення проєкту прибирає лише локальний індекс Rothbald і не чіпає вихідні медіафайли.
