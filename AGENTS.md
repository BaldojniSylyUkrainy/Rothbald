# Rothbald contributor instructions

- Read `READMEAI.md` before changing architecture, storage, transcription, search, packaging, or release behavior.
- Keep user-facing application text in Ukrainian.
- Never commit `data/`, model caches, transcripts, databases, media, virtual environments, build output, signing material, or credentials.
- Preserve local-first behavior: user media and transcripts must not be uploaded to external services.
- Run the Python test suite and JavaScript syntax check before committing changes.
